# 周末出逃计划 · 周末城市探索指南

面向大学生的周末活动推荐 H5 雏形：按 **天气 × 预算 × 同行人数** 实时排序本地活动，支持组队出发、打卡徽章与攻略分享。

🔗 在线访问：<https://jongtywang.github.io/weekend-escape-plan/>

## 核心功能

- **智能推荐** —— 偏好（展览 / 市集 / 演出 / 徒步 / 骑行 / 咖啡）× 当日天气 × 预算 × 同行人数 → 匹配分 + 推荐理由；切换周六（晴）/ 周日（小雨），列表实时重排，雨天自动倾向室内，超预算活动降权并说明原因
- **组队出发** —— 加入 / 发起小队，集合时间地点、人数进度一目了然
- **打卡记录** —— 探索足迹时间线 + 成就徽章墙（首次出发 / 探索三连 / 风雨无阻 / 组队出发 / 攻略作者）
- **攻略分享** —— 同伴经验流，支持点赞与发布

## 实现说明

- 纯前端单页应用（原生 HTML / CSS / JS），零依赖、秒开，适配移动端与桌面端、自动适配深色模式
- 雏形阶段使用示例数据演示产品逻辑；全部交互真实可用，数据保存在浏览器本地
- 部署：GitHub Pages（deploy from branch main），push 即自动重新发布
